winnow context <session-id> — visual mockup

proposals/ContextTreemap · mockup only · nothing here reads a file, resolves an id, or parses a transcript. Every number is hard-coded from 06-spike-findings.md.

The spike amended the recommendation before this was drawn, so this draws the amended shape: a ranked receipt with exact facts above it, not a treemap; the third level demoted to an opt-in and re-keyed artefact-first; and a new exact block above the tree for context that left the window with no compaction boundary. Figure 5 shows why the treemap was dropped.

exact — read from usage.{input,cache_creation,cache_read}_tokens on the anchoring request.
derived — an exact number minus an estimate. Material that is in the window and not in the file.
est — payload characters / 2.6. The band is 2.4–3.0 and it is the whole error bar.
residual — window minus everything above it. May be negative. It is the confession, not a category.
unknown — in the window, in no record type, not separable. Deliberately unsized: no bar is drawn, because there is no length to draw.
Every row states its own kind. Colour never carries the claim alone, and no figure prints a “% of window full”: nothing in a transcript states the window size.
